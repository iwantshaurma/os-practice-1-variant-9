# Практическая работа №1 — Загрузчик операционной системы

* **Вариант:** 9 (попиксельная фигура — треугольник в левом верхнем углу; текст — в правом нижнем углу)
* **Автор:** Казарина Виктория Максимовна
* **Группа:** НМТ-343901

## Состав проекта
* `boot_2.ASM` — исходный код 16-битного загрузчика для реального режима (графический режим `13h`, 320×200).
* `font16_2.ASM` — растровый шрифт 8×16 (512 байт).

## Сборка образа
Для компиляции используется компилятор **FASM** (`fasm.exe`):

```cmd
fasm.exe boot_2.ASM boot.bin
fasm.exe font16_2.ASM font16.bin
copy /b boot.bin + font16.bin myboot.img
